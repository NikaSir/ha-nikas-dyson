# Changelog

## 0.1.6 · UI 1.0.3 — 2026-09-13

- Заголовок панели открывает объявленный родительский маршрут и не использует
  конфликтующий источник перехода.
- Добавлены проверки поведения навигации для конфликтующих источников.

## 0.1.5 · UI 1.0.2 — 2026-09-13

- Панель переведена на автономную production-сборку по NikaS UI Standard 2.2.
- Исправлены состояния недоступных и устаревших данных, логика сеансов и
  привязка источников телеметрии.
- Добавлены проверки доставки, версий, исходных хешей и браузерных сценариев.
- Добавлена утверждённая MIT License и локальный бренд-ассет интеграции.

## 0.1.4 — 2026-09-09

- Исправлено сохранение найденных привязок телеметрии розеток между
  перезапусками Home Assistant.

## 0.1.3 — 2026-09-08

- Настроенные розетки дополнены найденными датчиками мощности и энергии.
- Обновлены пояснения настройки источников.

## 0.1.2 — 2026-09-08

- Привязка источников розетки сделана атомарной и устойчива к неполным данным.
- Усилена обработка вариантов конфигурации.

## 0.1.1 · UI 1.0.1 — 2026-09-08

- Добавлен автоматический поиск телеметрии известных розеток Dyson.
- Исправлены первая компоновка панели, загрузка полного bundle и UI hotfix.

## 0.1.0 · UI 1.0.0 — 2026-09-08

- Создана локальная read-only интеграция для наблюдения за шестью устройствами.
- Добавлены модель устройств, настройка источников, координатор, расчёт сеансов
  и энергии, сенсоры и специализированная панель.
- Добавлены HACS-метаданные, русская локализация и базовый CI.
