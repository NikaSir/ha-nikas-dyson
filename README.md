# NikaS Dyson · Техника

Интеграция Home Assistant для наблюдения за шестью устройствами через существующие розетки и датчики мощности/энергии:

- Dyson V15 · Гардероб
- Dyson V12 · Кухня
- Dyson V8 · Гараж
- Пылесос LG
- S8 · розетка
- Массажное кресло

Версия интеграции: **0.1.5**. Интерфейс: **UI v1.0.2**. Панель: `/dashboard-dyson`.

## Установка

Добавить репозиторий `NikaSir/ha-nikas-dyson` в HACS как пользовательский репозиторий типа **Integration**, установить, перезапустить Home Assistant и добавить интеграцию **NikaS Dyson** через «Устройства и службы».

Для трёх Dyson известные выключатели `switch.socket_zb_24`, `switch.socket_zb_22`, `switch.socket_zb_4` используются автоматически. Если у соответствующей розетки Home Assistant видит ровно один датчик мощности с `device_class: power`, интеграция привязывает его автоматически; единственный накопительный датчик `energy` привязывается так же. При неоднозначности датчик не угадывается.

Для LG, S8 и массажного кресла источники нужно назначить через **NikaS Dyson → Настроить**, потому что их фактические entity_id пока не зафиксированы.

Обязателен датчик мощности W/kW. Накопительный счётчик энергии Wh/kWh необязателен. Без него энергия оценивается интегрированием мощности. Пороги зарядки/работы сначала остаются неподтверждёнными и калибруются по реальным графикам.

## Достоверность

Интеграция не управляет питанием и не отправляет команды устройствам. Процент заряда аккумулятора не вычисляется. Состояние **«Заряжен · оценка»** выключено по умолчанию и может использоваться только после подтверждённого сеанса и калибровки порогов.

Панель содержит вкладки **Состояние / Сеансы / Статистика / Диагностика**, фиксированные header и нижнее меню, переключатели шести устройств с лампами состояния и подтверждение обновления галочкой.

При потере связи текущая мощность и активный сеанс больше не отображаются как актуальные: панель показывает устаревшие данные. История сохраняется с пояснением. После восстановления связи состояние обновляется автоматически.

## Настройка источников и порогов

Администратор может открыть настройки из панели или через «Устройства и службы». Выберите устройство, назначьте источники мощности, энергии и присутствия вручную либо оставьте поиск датчиков той же розетки. Ручное назначение имеет приоритет. Устройство можно отключить без повторного автоматического включения после перезапуска.

На следующем шаге задайте пороги начала и окончания сеанса, задержки, минимальную длительность и срок актуальности данных. Подтверждайте калибровку только после проверки реального графика. При смене источников подтверждение сбрасывается. Оценка полного заряда и расчёт стоимости по тарифу включаются отдельно.

## Проверки разработки

Production-панель собирается командой `python scripts/build_frontend.py` в один файл без дополнительных импортов. Проверка `python scripts/check_panel_contract.py` сверяет сборку, версии и контрольные суммы исходников специализированной оболочки.

CI выполняет Python-регрессии, браузерные сценарии, Hassfest и HACS. Общий `validate` успешен только при успехе всех проверок. HACS использует явное исключение `topics` для пользовательского репозитория. Обязательность `validate` при слиянии задаётся отдельно в защите ветки GitHub.

Браузерные тесты используют имитацию ответа Home Assistant. Работа на реальных устройствах, калибровка порогов и проверка в установленном Home Assistant остаются неподтверждёнными.
