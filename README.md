# NikaS Dyson · Техника

Интеграция Home Assistant для наблюдения за шестью устройствами через существующие розетки и датчики мощности/энергии:

- Dyson V15 · Гардероб
- Dyson V12 · Кухня
- Dyson V8 · Гараж
- Пылесос LG
- S8 · розетка
- Массажное кресло

Версия интеграции: **0.1.1**. Интерфейс: **UI v1.0.0**. Панель: `/dashboard-dyson`.

## Установка

Добавить репозиторий `NikaSir/ha-nikas-dyson` в HACS как пользовательский репозиторий типа **Integration**, установить, перезапустить Home Assistant и добавить интеграцию **NikaS Dyson** через «Устройства и службы».

Для трёх Dyson известные выключатели `switch.socket_zb_24`, `switch.socket_zb_22`, `switch.socket_zb_4` используются автоматически. Если у соответствующей розетки Home Assistant видит ровно один датчик мощности с `device_class: power`, интеграция привязывает его автоматически; единственный накопительный датчик `energy` привязывается так же. При неоднозначности датчик не угадывается.

Для LG, S8 и массажного кресла источники нужно назначить через **NikaS Dyson → Настроить**, потому что их фактические entity_id пока не зафиксированы.

Обязателен датчик мощности W/kW. Накопительный счётчик энергии Wh/kWh необязателен. Без него энергия оценивается интегрированием мощности. Пороги зарядки/работы сначала остаются неподтверждёнными и калибруются по реальным графикам.

## Достоверность

Интеграция не управляет питанием и не отправляет команды устройствам. Процент заряда аккумулятора не вычисляется. Состояние **«Заряжен · оценка»** выключено по умолчанию и может использоваться только после подтверждённого сеанса и калибровки порогов.

Панель содержит вкладки **Состояние / Сеансы / Статистика / Диагностика**, фиксированные header и нижнее меню, переключатели шести устройств с лампами состояния и подтверждение обновления галочкой.
